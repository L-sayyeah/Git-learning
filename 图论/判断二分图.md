# 判断二分图

## 1.二分图

设G=(V,E)是一个无向图，如果顶点V可分割为两个互不相交的[子集](https://so.csdn.net/so/search?q=子集&spm=1001.2101.3001.7020)(A,B)，并且图中的每条边（i，j）所关联的两个顶点i和j分别属于这两个不同的顶点集(i in A,j in B)，则称图G为一个二分图。即图中节点可以分为两组，每条边都连接两组中的两个点。

![img](https://i-blog.csdnimg.cn/blog_migrate/7af8364605063dbb52e49c01cef387c1.png)

判断二分图的充要条件：**图中每个环的长度都是偶数**。



## 2. 染色法判断二分图

### 2.1算法思路

* 规定1或2代表一个点属于两个集合
* 先将某个点染色为1，并将与其相连的点染色为2
* 同样染色为2的点将其相连的点染色为1
* 如果在染色过程中，该点为未染色，或者本身着色与之相匹配，则不出错，如果已染色，且着色不匹配，则不为二分图。

### 2.2代码模板

* DFS实现

```C++
//初始化
color[N];//存放N个节点的color;
memset(color,0,sizeof color);//未染色状态为0

//dfs染色
bool dfs(int u,int c)//u代表节点编号，c代表染成的颜色
{
    color[u]=c;//将节点u染成c色
    //遍历子节点
    for(int i=h[a];i!=-1;i=ne[i]){
        int j=e[i];
        if(!color[j]){//如果j未被染色
            if(!dfs(j,3-c)) return false;//从j开始dfs染色，如果染色冲突则返回false
        }
        else if(color[j]==c)return false; //如果j已染色，并且染色冲突，则返回false
    }
    return true; //如果没有染色冲突，则返回true，代表这一块连通图已经染色成功。
}

//完成整个图的染色
bool flag=true;//代表最终结果
for(int i=1;i<=N;i++)//考虑到图不连通，需要遍历每个点
{
    if(!color[i])continue; //已染色则跳过
    if(!dfs(i,1)) {//某个连通图染色失败
        flag=false;
        break;
    }
}
```

* BFS实现

```c++
//初始化
color[N];//存放N个节点的color;
memset(color,0,sizeof color);//未染色状态为0

//bfs实现
for(int i=1;i<=n;i++){
	if(color[i]!=0)continue;
    int c=1;
    queue<int> q;
    q.push(i);
    color[i]=c;
    while(!q.empty()){
        int s=q.front();q.pop();
        c=3-color[s];//转换颜色
        for(int j=h[s];j!=-1;j=ne[j]){//遍历相连节点
            int end=e[j];
            if(color[end]==0){//未染色则染色
                color[end]=c;
                q.push(end);
            }
            else if(color[end]=color[s]){//与start节点颜色相同，冲突
                flag=false;
                break;
            }
        }
    }
	if(!flag)break;
}
```

### 2.3算法分析

* 时间复杂度：O(V+E),V表示节点数，E表示边数
* 算法应用场景：
  * **社交网络**：判定两类用户之间的关系（如朋友和敌人）。
  * **调度问题**：分配任务给不同的机器，以确保冲突最小化。
* 缺点：只适用于判断二分图，对于其他类型的图（如有向图）需要不同的方法。

## 3.匈牙利算法寻找最大匹配

### 3.1算法思路

* 初始时，二分图左右均未匹配。
* 从左边开始匹配，遍历与该点相连的右节点，如果该节点未被匹配，则匹配左右节点；或者该节点已经匹配的左节点还存在没有被匹配的备胎右节点，则将该左节点与其备胎右节点匹配，并将本左节点与该右节点相匹配。
* 匹配成功一组，匹配数加一。

### 3.2算法模板

```c++
//DFS 实现
//初始化
int h[N],ne[M],e[M],idx;//用来存左右节点的连接关系。
int match[N];//用来存右节点匹配的左节点
bool flag[N];//这个理解比较繁琐，具体是每为一个点匹配的时候保证每个右节点只匹配一次，防止重复匹配同一个右节点陷入循环。
memset(match,0,sizeof match);
//匹配规则
bool find(int x){
	for(int i=h[x];i!=-1;i=ne[i]){//遍历相连接的右节点
		int j=e[i];
		if(!flag[j]){//如果这个右节点未尝试匹配过
			flag[j]=true;
			if(match[j]==0||find(match[j])){//如果这个右节点未匹配，或者他的原配能找到备胎
				match[j]=x;
				return true;//匹配成功
			}
		}
	}
	return false;//所有右节点都尝试后，匹配失败
}
//匹配流程
int res=0;//存匹配数
for(int i=1;i<=n;i++){//为左节点挨个匹配
    memset(flag,false,sizeof flag);//初始时，保证每个右节点都可以尝试
    if(find(x)) res++;//匹配成功，匹配数+1
}


//BFS 实现
```

### 3.3算法分析

无论是使用 DFS 还是 BFS，两个版本的时间复杂度均为 O(V*E)。对于稀疏图，BFS 版本明显快于 DFS 版本，对于稠密图，两者不相上下，因而当图为稀疏图时，常选用 DFS 版本，当图为稠密图时，常选用 BFS 版本。
