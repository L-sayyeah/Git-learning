# 最小生成树

## 1.Prim算法

### 1.1算法流程

* 算法初始化，trackSum=0记录路径长度，cnt=0记录加入连通图的节点个数。used数组记录节点有无加入连通部分。
* 将used[1]设为true，cnt+1，将所有以1为起点的边的终点和权重加入最小堆。
* 遍历最小堆，如果used[e]=false；将used[e]设为true，加入连通部分，trackSum+=w;cnt++;遍历与e为起始的边，如果对应终点并未加入到连通部分，则将终点和权重加入最小堆。
* 当cnt=n时或者最小堆为空，退出循环。

### 1.2算法模板

```c++
//初始化
trackSum=0;
used[1]=true;
for(int i=h[1];i!=-1;i=ne[i]){
    minHeap.push({w[i]},e[i]);
}
cnt=1;
//循环
while(minHeap.size()&&cnt<n){
	int item = minHeap.top();minHeap.pop();
    int b=item.second,c=item.first;
    if(!used[b]){
        used[b];
        cnt++;
        trackSum+=c;
        for(int i=h[b];i!=-1;i++){
			if(!used[i]){
                minHeap.push({w[i],e[i]});
            }
        }
    }
}

//判断结果
if(cnt==n)cout<<trackSum;
else cout<<"impossible";//非连通图
```

### 1.3 分析

**使用邻接矩阵和简单数组**：

- 时间复杂度为 O(V2)，其中 V是图中的顶点数。这种方法在图的顶点数较小且稠密时效率较高。

**使用邻接矩阵和最小堆（优先队列）**：

- 时间复杂度为 O(Elog⁡V)，其中 E是图中的边数，适合稀疏图。最小堆可以加快找到当前最小边的速度。

**使用邻接列表和最小堆**：

- 也是 O(Elog⁡V)，在处理稀疏图时非常高效，特别是在边的数量远小于顶点数的情况下。

## 2.Kruskal算法（并查集实现）

### 2.1算法流程

* 每个节点为单独的一个连通图，将边从小到大排序。
* 遍历边，如果发现起点和终点不属于同一个连通图，则连通两个集合，如果属于一个连通图则略过（防止出现环路），同时记录加入的边数以及路径和。
* 继续上一步，直到加入边数等于n-1（所有节点连通），或者边被遍历完（如果加入边数小于n-1,说明原图本就不是连通图）

### 2.2 算法模板

```c++
//初始化
int p[N+1];//N为节点，p记录父节点（并查集以树存集合）
for(int i=1;i<=N;i++)p[i]=i;//初始时，每个集合单属于一个集合
//最小堆存边
priority_queue<edge> q;
for(auto e:edges)q.push(e);
int trackSum = 0;//路径和
int edgeCnt=0; //加入边数
//路径压缩的并查集查找操作
int find(int x){
    if(x!=p[x])p[x]=find(p[x]);
    return p[x];
}

//遍历所有边
while(!q.empty()&&edgeCnt<N-1){
    int e = q.top();q.pop();
    int a=e.a;int b=e.b;
    if(find(a)==find(b))continue;//同一个集合
    else {
        trackSum+=e.w;
        edgeCnt++;
        p[find(a)]=find(b);//合并两个集合
    }
}

//结果
if(edgeCnt==N-1)cout<<trackSum;
else cout<<"不连通";
```

### 2.3算法分析

* 时间复杂度：主要是边排序：O(MlogM)
* 适用于边数较少的稀疏图。



**Kruskal**：适用于边稀疏、边列表存储的图，尤其是当图的结构静态时。

**Prim**：适用于边稠密、邻接矩阵存储的图，尤其是在需要动态更新图的情况下。
