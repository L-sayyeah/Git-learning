# 扩展欧几里得

## 1.扩展欧几里得

### 1.1扩展欧几里得是什么

* 欧几里得回顾：

  * 对于$a$ 和 $b$ 的最小公约数$d$  ,满足$x*a+y*b=kd$ (k∈Z)

  * 满足  gcd(a,b)=gcd(b,a%b)

* 根据欧几里得算法，可以得知存在 一组$(x,y)$使得$x*a+y*b=d$  ，$(x,y)$被称为**贝祖系数**

  * 而贝祖系数就是扩展欧几里得的求解对象。

### 1.2 扩展欧几里得用于求解什么问题

* 求解线性不定方程 ： $x*a+y*b=d$ 
* 求解模反元素（线性同余方程）：  $x*a+y*b=kd$  或 $a \cdot x \equiv 1 \pmod{m}$

## 2.求解贝祖系数

### 2.1 问题

* 给定 $n$ 对正整数 $a_i,b_i$，对于每对数，求出一组 $x_i,y_i$，使其满足 $a_i*x_i+b_i*y_i=gcd(a_i,b_i)$

### 2.2 求解思路

* base case : 当$b=0 $ ,可以得知$x=1,y=0$ 
* $b!=0$,从后往前推：
  * gcd(a,b)=gcd(b,a%b) 
  * 其中对于gcd(a,b)： $a*x_1+b*y_1 = gcd(a,b)=d$
  * 对于gcd(b,a%b)  ： $b*x_2 + (a-\lfloor a/b\rfloor *b)*y_2=d$
  * 只有一组解得:$a,b$ 前系数相等：
    * $x_1 = y_2$ 
    * $y_1=x_2-\lfloor a/b\rfloor * y_2$

### 2.3 代码实现

```c++
int exgcd(int a,int b,int &x,int &y){
	if(!b){
		x=1;y=0;
		return a;
	}
	int d = exgcd(a,b,y,x);//这里x,y交换位置主要方便计算，可以根据上面的公式理解
	y-=x*a/b;
	return d;
}

//不交换x,y
int exgcd(int a,int b,int &x,int &y){
    if(!b){
        x=1;y=0;
        return a;
    }
    int d=exgcd(b,a%b,x,y);
    int temp = x;
    x = y;
    y = temp - a / b * y; 
    return d;
}
```

## 3.求线性同余方程

### 3.1问题描述

* 给定 n 组数据 $a_i,b_i,m_i$，对于每组数求出一个$x_i$，使其满足$a_i*x_i\equiv b_i(mod \ m_i) $，如果无解则输出 `impossible`。

### 3.2 求解思路

*  $a_i*x_i\equiv b_i(mod \ m_i)$ 等价于$a_i*x_i + m_i*y_i = d $ 且  $b\  mod\ d=0$

* 根据扩展欧几里得，只需要求出 最大公约数$d$ ,可以求得$x = b/d*x_i $ (满足 $b\  mod\ d=0$)，否则为impossible。

### 3.3 代码模版

```c++
int exgcd(int a,int b,int &x,int &y){
	if(!b){
		x=1;y=0;
		return a;
	}
	int d = exgcd(a,b,y,x);//这里x,y交换位置主要方便计算，可以根据上面的公式理解
	y-=x*a/b;
	return d;
}
int a,b,m;
int x,y;
int d=gcd(a,m,x,y);
if(b%d)cout<<"impossible" <<endl;
else cout<<b/d*x<<endl;
```
