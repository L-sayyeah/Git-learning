# 简单数学问题--质数

## 1.质数问题

### 1.1代码模板

```c++
bool is_prime(int a){
    if(a==1)return false;
    if(a==2)return true;
    for(int i=2;i<=a/i;i++){	//因为i*a/i<=a;因此i不可能大于a/i
		if(a%i==0)return false;
    }
}
```

### 1.2 算法分析

时间复杂度O(sqrt(a)).



## 2.分解质因数

### 2.1代码模版

```c++
bool divide(int a){
    for(int i=2;i<=a/i;i++){//因为i*a/i<=a;因此i不可能大于a/i
        if(a%i==0){
            int cnt=0;
            while(a%i==0){
                cnt++;
                a/=i;
            }
            cout<<i<<" "<<cnt<<endl;
        }
    }
    if(a>1)cout<<a<<" "<<1<<endl;//如果最后a>1;则说明最后一个因子是a
}
```

### 2.2分析

时间复杂度为O(sqrt(a))

## 3.质数问题PLUS

### 3.1问题描述

​	1~n中质数有多少个

### 3.2 解决方法

#### 3.2.1 朴素筛法

* 从2-n开始遍历每个数，如果该数已经被判定为非质数，则跳过，如果该数为质数，则将小于n的该数的倍数都设置为非质数。

```c++
bool flag[n+1];//标记是否非质数
int cnt=0;//记录质数个数

for(int i=2;i<=n;i++){
    if(flag[i])continue;//如果已被标记则跳过
    cnt++;//如果未被标记，则为质数
    for(int j=i+i;j<=n;j+=i){
        flag[j]=true;
    }  
}
```

#### 3.2.2线性筛法

* 同样从2-n开始遍历每个数
* （如果该数未被标记，则其为质数，cnt++）我们遍历所有以出现的素数，并将flag[i*prime[j]]设为true，当i%prime[j]==0时，退出循环
* 原理：线性筛法中，i是质数就筛掉i与primes中所有质数的乘积；i是非质数筛掉i与primes中所有<=最小质因子的乘积

```c++
bool flag[n+1];//标记是否非质数
int prime[n];记录出现的质数
int cnt=0;//记录质数个数

for(int i=2;i<=n;i++)
{
   	if(!flag[i])prime[cnt++]=i;
    for(int j=0;prime[j]<=n/i;j++){
        flag[i*prime[j]]=true;
        if(i%prime[j]==0)break;
    }
}
```

### 3.3算法分析

* 朴素筛法：时间复杂度O(nloglogn)
* 线性筛法：时间复杂度O(n)
* 线性筛法比朴素筛法在筛选过程中不会重复筛选一个数。
