# 并查集

## 1.作用

* 将两个集合合并
* 询问两个元素是否在一个集合中

 ## 2.基本思想

* 用树存储集合，每个节点都存父节点
* 通过不断查找该节点的父节点（p[x] 表示 x的父节点），直到找到根节点，根据根节点来判断该元素属于哪个集合
  * 判断是否为树根，p[x]=x
  * 根节点作为集合编号：while(p[x]!=x) x =p[x];
* 合并两个集合，其中一棵树的根节点接到另外一棵树的根节点。
  * p[x]=y;

## 3.算法优化

### 路径压缩

对于查找根节点而言，算法时间复杂度高，可以使用路径压缩：每当搜索到根节点，将搜索路径上的所有点指向根节点

## 4. 算法模板

```c++
//初始化
int p[N];
for(int i=0;i<N;i++)p[i]=i;//初始时，根节点就是自身

//查找操作
//不带路径压缩
int find(int x){
    while(p[x]!=x) x=p[x];
    return p[x];
}
//带路径压缩
int find(int x){
    if(x!=p[x])p[x]=find(p[x]);
    return p[x];
}

//合并集合
p[find(a)]=find(b); //a所在集合的根节点指向b所在集合的根节点
```

### 5.算法分析

时间复杂度：路径压缩后，find和union操作时间复杂度均为O(1)
